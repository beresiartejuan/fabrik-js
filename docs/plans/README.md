# Archivo histórico — planes de implementación

Esta carpeta conserva la cronología original de implementación del proyecto:
los planes numerados por fase (`01`–`11`), con el estado del proyecto en cada
momento y los enlaces internos tal como se escribieron entonces. Es material
de archivo: los enlaces a otros documentos pueden estar desactualizados. La
documentación vigente está en [`docs/*.md`](../README.md).
